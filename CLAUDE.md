# Sobre este repositorio

- Landing page de una sola página para un consultorio dental en Cuenca.
- Tecnología: HTML, CSS y JavaScript "a pelo" (sin frameworks ni librerías, sin paso de compilación).
- Se publica con GitHub Pages, así que `index.html` debe estar en la raíz del repositorio.
- Debe verse bien en el celular (diseño "mobile first").

# Estructura

- `index.html` — el contenido de la página (textos, secciones).
- `styles.css` — los colores, tamaños y la maquetación.
- `script.js` — pequeñas interacciones (menú del móvil, enlace de WhatsApp, año del pie de página).

# Datos de ejemplo

El nombre de la clínica, la dirección, el teléfono y los horarios son **inventados**.
Antes de publicar, cambia:
- El número de WhatsApp en `script.js` (constante `WHATSAPP_NUMBER`).
- Dirección, teléfono, horarios y el mapa en `index.html`.
